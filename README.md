Project Information
=======
This is an unofficial work-in-progress (without eta release date) port of the [Galacticraft-Legacy](https://github.com/TeamGalacticraft/Galacticraft-Legacy) mod for modern versions of Minecraft. Mod will be released only in a stable release version and needs a blessing from the **Team Galacticraft**.

## Current progress can be seen in the [Feature Tracker](./FeatureTracker.md)

---

### AI Usage
This project relies mostly on human-written code, the only thing generated by LLM was [tool_migrator.py](./tool/model_migrator.py) which helped rewrite legacy model format.
